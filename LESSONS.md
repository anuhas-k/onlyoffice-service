# Captures what went wrong, what worked, and what to do differently.

---

## How to use

After Phase 7 (Ship) completes, run `/pm lessons` to extract lessons from the sprint.
Or add entries manually as you discover patterns.

Each lesson follows this format:
```
## [Sprint / Feature name] — [Date]
### What went wrong
- [concrete thing that broke or slowed you down]
  → Fix: [what to do differently next time]

### What worked well
- [concrete thing that saved time or caught a bug early]
  → Keep: [how to repeat this]

### Checklist additions
- [anything that should be added to a role checklist so this never happens again]
```

## How to query lessons

```

/pm lessons add          → Add a new lesson interactively
```
